# The name "Kernel AI"

The code licences ([LICENSE](LICENSE), MPL-2.0, and the `MIT OR Apache-2.0` and `0BSD` parts) cover the code. They grant no rights in the name "Kernel AI" (MPL-2.0 section 2.3), and nothing here changes what they let you do with the code.

- **Unmodified releases.** A build of a tagged release, unchanged, may be called Kernel AI, and you may say so when you share it.
- **Modified builds.** If you change the code and share the result, give it another name, or call it "based on Kernel AI". Change the name the banner and the boot entry show: it is `kabi::PRODUCT_NAME`, in one place. Changing the name changes the AI's prompts too, which is expected.
- **Talking about it.** You may always use the name to refer to the project, to say your work is compatible with it, or to write about it, as long as you do not suggest the project endorses you.

The name has not been registered yet; a clearance search comes before the v0.1 release (ADR [0009](docs/adr/0009-licence.md) D8). Questions about the name go to the maintainer in [MAINTAINERS](MAINTAINERS).

decision: A model trial holds through a second switch, a busy `llm`, a restart of `updated` and a failing LLM server; this amends the P4 rows on `modelchan` and on `updated` serving the model channel
---
**No switch while a boot judges a trial (#25).** `models use` (so `model_use` and its undo) is refused during the probation, as an import and a download are: "a model is on trial; ask again once it is kept or rolled back". An attempted trial is no longer replaced or cancelled (`trial::switch` gives `Switch::OnTrial`), and the verdict is written only over that trial's record as it stands (`trial::verdict`). Before, a switch then was overwritten by the old verdict, so the new model booted untried, or the acknowledged switch was lost.

**The way back is never guessed (#26).** A new trial's previous model is the one the next restart maps, as the record names it: a pending trial's way back (kept when the trial is replaced; switching to it cancels the trial and points the hint at it), a kept candidate, or the model a rollback put the hint back on, even while this boot still runs the candidate. Only with no record is it the model `llm` runs, and when `llm` cannot say (no answer in time, or an app job's health that names no model) the switch is refused, "llm did not say which model it runs; ask again". Before, it recorded none, and a failed trial went back to no model. `models remove` holds to the same reading. After a rollback, the list's next model is the one the hint names.

**A restart of `updated` is not a hung boot (#27).** The supervisor now counts a restart the user asked for in the `restart=N` every start gets (not against the cap or the backoff). Its records are the kernel's, in memory, so N is 0 at every boot's first start. A start with N > 0 that finds the trial attempted points the hint back at the previous model at once, keeps the record, judges the candidate again, and on a keep points the hint at it again; a pending trial it finds was written this boot for the next restart, and is not judged. The first start of every boot keeps K's rule as it was, and the hint is never left on a candidate while a start judges a trial it did not mark, so a candidate that hangs a boot is still not tried again.

**A failing server does not hide the local model (#28).** When `llm`'s server's health fails beside a local model, `health` is still an error but ends with the local status, cut to the 160-character error line with the model's words kept (`llmproto::health::reply`). The probation, a switch and a remove wait 6 s for `health` (`trial::HEALTH_WAIT_MS`), longer than `llm`'s 5 s wait on the server (`llmproto::health::SERVER_HEALTH_MS`); the list keeps 3 s, within the model manager's 5 s read. `llm`'s no-model error now reads as no model (`health::state_of`), so such a trial rolls back at once ("no model started"), not after 300 s.

Host-tested in `modelchan`, `llmproto` and `supervise`; the `model-import`, `ui-models-use` and `app-models` boot cases run it under `full-ci`.

needed-by: Agents, built 2026-11-11 (lane E; ADR 0013 sections 1 and 3; follows the `kaimem` finding in the random-sequence tests; host only)
decision: No package may name its agent `all`: it is the word `kai-memory 1` uses for the memories every agent sees, so an agent so named would be read back as everyone
---
`all` has the shape of an agent name (2 to 12 of `a-z`, `0-9` and `-`) and is not one of the four built-in names, so a manifest with `id all` was an installable agent. `kai-memory 1` writes a memory for every agent as `scope=all` and reads `scope=all` as every agent's, so a private memory of an agent named `all` read back after a restart as everyone's (the `kaimem` store now refuses to keep one, so such an agent keeps no private memories). `kaiagent::RESERVED` (`all`) is the list of names that are no agent's because a file that names agents gives them a meaning of its own; `Manifest::parse` refuses them with `Refusal::ReservedName`, as it refuses a built-in agent's name, so the roster never holds one. Names that merely start with it (`all-in`, `ally`) are agents' names as before.

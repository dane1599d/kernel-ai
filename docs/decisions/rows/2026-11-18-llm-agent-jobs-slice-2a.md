needed-by: Agents, built 2026-11-18 (lane AG; ADR 0013 section 2, row F3 of docs/plans/agents-os.md, slice 2a; the manager assigned F3 to AG, lane M shares user/src/bin/llm)
decision: llm serves agents' `script` and `ask` requests as jobs, run whole in idle turns, and an interrupted job starts again from its prompt; an agent's `act` request is refused until the scheduler's quanta drive the engine (slice 2b)
---
Agents send `agent-start script\|ask <request>` on their own route, then `agent-take` and `agent-stop` (`agentsched::jobs`). The route's badge is the kernel's, through #982. llm receives with `RECV_H` and keys jobs by `RecvInfo::badge` alone (`jobs::Caller`). The caller's pid is never an identity: the first cut read `svc_recv`'s caller, which is the pid, so a process with pid 2 would have been `goals` (the manager's HIGH on #1008). A test now holds a pid equal to a built-in badge number, with no badge, to nothing. Badge 0 and `kai` start no job, so before #982 every route is refused and nothing changes. Handles a request moves to llm are closed at once. llm admits a job through `Scheduler::submit`, with the refusals in the ADR's words and its prompt's tokens estimated from its bytes. A job runs only once both slots are warm and no request waits, one at a time: the highest class first, then the oldest. On the local model it asks every 50 ms whether a request came. If one did, the job stops at that engine step, the request is answered next, and the job starts again from its prompt in a later idle turn. That is exact, since a request's answer depends only on its prompt and the sampler's start (the row `2026-11-18-agentsched-grammar-preemption`). The person waits at most about 50 ms and the step in flight. What a finished job computed and made is charged to its agent's day (`Scheduler::charge_whole`). A job uses the script slot, so the script prompt is warmed again after it, before the next job. On a server backend a job runs as one call and cannot be stopped; that backend is CI's test double. An agent's `act` is refused ("not served yet"): it would read the person's conversation memory and take the act slot. It comes with slice 2b, where the scheduler's quanta drive the engine as `agentsched/tests/engine.rs` does, with a history of the agent's own. The foreground path gains one prefix check and nothing else.

decision: A grammar-shaped answer (`act`'s call, `script`'s code) keeps the model until it ends unless a higher class waits; whatever interrupts it starts it again from its prompt, which stays cached, so the person's request still waits for one token at most and every answer stays exact
---
The engine cannot carry a grammar answer on after a stop: `continue_reply` takes no shape, and the grammar's state lives inside one `reply_under` call. So `Ask` gains `shape: Shape::{Free, Grammar}`. An open grammar answer is one that has decoded a token and has not ended. While nothing of a higher class waits, it is the next lead (`Pick::Continue`), ahead of aging and the round robin of its own class, and its agent pays from what its visit has left, never below zero. Any decision other than its next token interrupts it and sets its count of decoded tokens back to 0. That covers another request's quantum and any move, including a free slot taken by the person's request. `End` is not a model step, so it does not interrupt. The answer starts again from its prompt the next time it runs. The prompt's cache is kept wherever its state went (slot, pool or spill), so nothing is prefilled again. The first token runs on the prompt and parts the cache there. The tokens decoded again are charged again, as a dropped state's prefill is. A grammar answer never joins a batch. The caller runs the answer as one `reply` under its shape and asks `Scheduler::next` after each token. It goes on only while the decision is this answer's next token. Otherwise it stops the call, drops the partial answer, starts the sampler again from the answer's start, and carries out the decision it got. The answer is exact because it depends only on the prompt and the sampler's state at its start. The cost is at most the tokens decoded before the interruption, once per interruption, and never the person's time. A request of the open answer's own class, even one past the aging bound, waits for the answer to end (at most `REQUEST_MS`). The aging bound in the crate docs holds for free answers only. A lever for later, not needed for exactness: if `infer` carried a grammar's `Constraint::State` across a stop, a grammar answer could pause and go on like a free one, and stop restarting. Tests: unit (the person interrupts and the answer restarts with its prompt run once and its 5 tokens charged twice; its own class and a past-aging agent never cut in; never batched; finishing it closes it). The random-workload props now include 30% grammar requests and check after every decision that only a higher class takes the model from an open answer, that whatever does sets it back to 0, and that it is never batched. `tests/engine.rs` does the same on the real engine over every tier, with 2 slots and with 1 (through the pool). The person's request arrives four tokens into a background agent's grammar answer and finishes first, and the restarted answer equals its answer alone, token for token. With the answer's cap set to its exact length, the rig fails if the restart is taken out.

The founder decided on 2026-11-16 to build Hold before P5 closes. ADR 0002 question 3 stands: every send asks, and `derive` still gives a `Hold` row Ask. After the person's Allow, whose ONCE names the call, the send waits `agentabi::HOLD_MS` (5 s) in the outbox (#958, #959) with `undo` live, then goes once, never retried or redirected, and never after a restart. `net_send(host, path?, text)` posts up to 4 KB of text to a host the line names, typed or a word of the host table. `consent` refuses any other host as `Why::SendHost`, with no card: one the model picked, one only an app's grant grounds, or one read content gave. Read content as the text or path asks as Steered and names its source. The row is in `agentabi::SEND_ROWS`, apart from `NET_ROWS`, so no script can call it. A `c>` program cannot make one either. The card offers no Always choice and says the send waits 5 s so you can undo. The menu line is at most 120 characters, so the call it shows (and its ONCE names) carries the first 16 hex digits of the text's SHA-256, as Kai's app install card carries its build's, and `show` prints the text. A send whose card cannot be shown is refused rather than asked as a y/n question no answer could allow. The pack names `net_send` in the `net` index group (gloss "web, send"): the pack and MODE take 980 real tokens, exactly the 980 alarm, so the next row needs headroom found first. The model's input changes by that one index entry, so the batch's fluency run is the gate. The boot case `net-hold` allows a send and sees it go once after its hold. It undoes another within its hold and sees it never go, and the HTTPS mock must have taken exactly one POST. It also sends to a site the line does not name and sees it refused. It needs lane C's real `Host::net_send` (PR 4a) and lands after it. The 2026-11-10 row's site-word half stands; its Hold half is superseded.

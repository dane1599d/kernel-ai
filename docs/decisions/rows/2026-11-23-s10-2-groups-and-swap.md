**The harness** (#1265): `cargo xtask groups --local qwen3-4b-2507 --gate`, run by `groups-model.yml` (PR 2) on a GitHub ubuntu-24.04 runner with the SHA-checked Qwen3-4B-Instruct-2507 Q4_K_M. Eight stub apps (todo, shopping, timer, alarm, weather, music, contacts, calendar; 22 rows, confusable in pairs) and 120 tasks: 80 for one app, 20 confusable, 20 for no app. Both arms go through llm's own `act` on the shipped pack, with llm's sampler. Arm **layered** is what llm ships: the apps turn holds index lines, a call naming an app row stops after the name and is written again with that app's lines after the request, at 3,072 positions (ADR 0010's context; llm itself loads at `CONTEXT_CAP` 2,048 today). Arm **flat** shows every app's full lines and writes each call in one round, at 4,096 positions. A task passes on its row with every expected argument; a no-app task on any call that names no app row.

**The gate** (both arms in one run): each arm answers every task with a call (no error and no full context, so a flat arm that never answered cannot pass the comparison); layered is at most 2 points under flat; layered names the right app on at least 95% of the 80 single-app tasks.

**Restore equals fresh** (PR 3, host, every tier): `infer`'s `a_swapped_group_segment_answers_as_a_fresh_one_on_every_tier` saves a `kai-kv 1` slot after one group's second round (pack, apps index turn, request, the to-do group's lines) and restores it for another group's (the timer's). The restore reuses the shared start, request included, and the reply equals a freshly computed slot's, token for token, on every tier; restored for its own group it reuses all but the last token. This is the fixture model; the guest's restore time is S10-3's.

**Limits.** llm draws with one fixed seed, so the run is one sample: against a 2-point bar about three of 120 tasks decide the gate, and a rerun is the same run. A seed list (as actbench takes) needs a seed parameter on llm's `act` sampler, which ships fixed; not added for a spike. If the gate passes by 3 points or less, a second sample (another seed through a harness-only sampler) is the cheap check before v0.2 relies on it.
